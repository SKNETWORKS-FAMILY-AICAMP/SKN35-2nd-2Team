# 스팀 리뷰 이탈 예측

게임 리뷰를 쓴 그 순간의 정보만으로, 이 사람이 게임을 그만둘지 맞힌다.

**데이터** 스팀 리뷰 139,658건 · 게임 60개 · 30개 언어 (2026-08-25 수집)
**정답** 리뷰 이후 추가 플레이가 1시간 미만이면 이탈 (41.1%)

---

## 시작하기

```bash
uv sync                              # 파이썬 3.12 + 패키지 (맥·윈도우 동일)
uv run streamlit run app/main.py     # 화면 실행
```

`data/processed/dataset.csv` 는 깃에 없습니다. 원본에서 다시 만드세요.

```bash
uv run python -m src.preprocess
```

## 폴더

```
src/        모델 코드
app/        Streamlit 화면 5개

results/    실험 기록 (results.csv) · 튜닝 로그
reports/    그림
docs/       산출물
notebooks/  탐색용
```

### 주요 파일

| 파일 | 하는 일 |
|---|---|
| `src/config.py` | 경로 · 인코딩 · 시드 · 누수 금지 목록 |
| `src/preprocess.py` | 원본 → 학습용 표. 라벨을 만드는 유일한 곳 |

| `src/predict.py` | 화면이 쓰는 예측 진입점 |

## 결과

영어 67,112행 기준

| 모델 | 랜덤 분할 | 게임 단위 분할 |
|---|---|---|
| 랜덤포레스트 (머신러닝) | 0.814 | 0.757 |
| AutoGluon multimodal (딥러닝) | 0.807 | 0.759 |
| **MLP + 글 (배포본)** | 0.786 | 0.730 |

세 가지를 확인했습니다.

1. **글만 봐도 맞힌다** — AUC 0.705 (동전 던지기 0.5)
2. **그런데 숫자에 더해도 안 오른다** — 글의 핵심 정보를 👍 버튼이 이미 알려준다 (글 → 추천 AUC 0.939)
3. **처음 보는 게임에서는 글이 이긴다** — 0.750 → 0.759

자세한 내용은 [학습 결과서](docs/02_학습결과서.md).

## 팀 규칙

- **원본 CSV 는 수정하지 않는다.** 전처리 결과는 항상 원본에서 다시 만든다
- **라벨은 `preprocess.py` 에서만 만든다.** 각자 만들면 정의가 갈라진다
- **정확도(accuracy)는 쓰지 않는다.** 이탈률이 41%라 아무것도 안 해도 59%가 나온다. AUC 를 쓴다
- **두 가지로 평가한다.** 랜덤 분할 + 게임 단위 분할. 두 점수 차이가 "게임을 얼마나 외웠나"
- **패키지는 `uv add` 로 추가한다.** `pyproject.toml` 만 고치면 `uv.lock` 이 어긋난다
- **`main` 에 직접 push 하지 않는다.** 역할별 브랜치로 PR
