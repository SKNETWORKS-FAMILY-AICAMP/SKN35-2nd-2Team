관측 창(리뷰 작성 후 180~545일)은 수집 단계에서 이미 적용되었습니다. 리뷰를 쓴 지 얼마 안 된 사람은 아직 더 플레이할 시간이 없어 자동으로 이탈로 찍히기 때문입니다.

이탈률 41.1% 가 뜻하는 것

우리가 선정한 60개 게임에서, 관측 창 안에 리뷰를 작성한 139,658명 중, 리뷰 작성 이후 추가 플레이가 1시간 미만인 사람의 비율입니다.

"스팀 유저의 41%가 이탈한다"리뷰를 작성한 사람만 대상입니다. 리뷰 작성자는 전체 유저의 일부입니다

표본이 적은 언어 처리 — 팀 검토 중 두 차례 발견하여 수정

설계 초안은 언어별로 중앙값과 표준편차를 모두 계산했습니다. 표본이 적은 언어에서 두 가지 문제가 연달아 나왔습니다.

차수발견증상
1차아랍어 1건 → 표준편차 계산 불가, 대체값 1.0200자 리뷰의 z 가 197
2차노르웨이어 197건이 전부 짧음 → 표준편차 752000자 리뷰의 z 가 26.5
같은 2000자가 영어에서는 3.6

2차는 표본 하한만으로는 막을 수 없는 문제입니다. 노르웨이어는 197건으로 하한(30건)을 여유 있게 넘겼지만, 그 197건이 모두 짧아서 표준편차가 과소추정됐습니다.

핵심 문제

언어끼리 값을 비교할 수 없다는 것입니다. 이 변수의 목적이 "언어차를 걷어내고 길이만 보기" 인데, 정반대 결과가 나왔습니다.

해결 — 언어별 표준편차를 쓰지 않고 전 언어 공통 표준편차를 씁니다. 언어마다 다르게 쓰는 것은 기본 길이(중앙값)뿐입니다. 성능을 실측해 확인한 뒤 결정했습니다.

판단 근거

언어별 표준편차는 성능 이득이 없었습니다. 이득이 없는데 버그가 생기는 쪽을 택할 이유가 없어 가장 단순한 방식을 골랐습니다.

추가 안전장치 — Z_CLIP = 10.0 으로 값의 범위를 제한합니다. 학습 데이터에서 여기 걸리는 것은 261행(0.19%) 이고 전부 3,000자 이상 리뷰라, "엄청 길다" 는 의미는 잘려도 보존됩니다.

트리 모델은 값의 크기가 아니라 순서만 보므로 영향이 없습니다. 그러나 로지스틱회귀·MLP 는 값을 계수에 곱하므로, 이 변수 하나가 예측을 지배할 수 있어 상한이 필요합니다.
